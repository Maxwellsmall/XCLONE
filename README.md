# XCLONE
XClone is a full-stack social media web application designed to replicate the core functionality, user interface, and real-time interaction model of X (formerly Twitter).

Features
Feed & Timeline: Post layout and media feeds built to match X's design and also to add some other custom design on our own.
Search: Custom search bar with active focus states and real-time filtering.
Interactive UI: Dynamic icon states, conditional rendering, active tab states, and modals.

we were about to do this and it was in progress before we got eliminated
Dark Mode: Theme toggling with next-themes and Shadcn UI.
Full Mobile Responsiveness: Finalizing layout adjustments for smaller viewports with some ither features..

Tech Stack
Framework: Next.js (App Router)
Styling: Tailwind CSS
UI Components: Shadcn UI
Icons: Lucide React
Package Manager: pnpm
